# Screenshots

Hier gehören die Bilder hin, die im [README](../../README.md) eingebunden
werden. Noch ist keins da.

## Was gebraucht wird

Wer sich das Repository ansieht, will in dieser Reihenfolge wissen: *Wie sieht
die Startseite aus? Was macht das ungewöhnlichste Modul? Wie sieht die Arbeit
mit Noten aus?* Drei bis fünf Bilder reichen — mehr veralten nur schneller.

| Datei | Ansicht | Warum |
| ----- | ------- | ----- |
| `start.png` | Startseite nach dem Anmelden | zeigt Rahmen, Navigation und was Nuvora überhaupt ist |
| `module.png` | `/modules` — die Modulübersicht | erklärt das Zuschalten besser als jeder Absatz |
| `cardvote-session.png` | CardVote, Live-Ergebnisse am Beamer | das Alleinstellungsmerkmal: Abstimmen ohne Geräte |
| `auswertung.png` | Notenbuch mit Gewichten und Belegung | zeigt, dass es keine Zeugnisnote ausrechnet |
| `lernpfad.png` | Lernpfad mit Lernleitern | die eingebettete Vanilla-JS-App im Rahmen |

## Regeln

- **Keine echten Schülerdaten.** Auch keine, die „eh nicht lesbar" sind — auf
  einem Screenshot ist alles lesbar. Ein frisch registriertes Konto legt
  Beispielinhalte an; die reichen. Sonst erfundene Namen.
- **Kein Konto- oder Kontextfenster mit E-Mail-Adresse**, keine URL mit
  Token (`/lernen/<token>`, `/cd/<code>`), kein QR-Code.
- Helles Design, Desktop-Breite, PNG. Ein Handy-Bild schadet nicht.
- Beim Umbau einer Seite **das Bild mit ersetzen** — ein veralteter Screenshot
  ist schlimmer als keiner.
